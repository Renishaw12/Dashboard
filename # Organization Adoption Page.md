# Organization Adoption Page

## Purpose

The **Organization Adoption** page shows how widely and effectively GitHub Copilot is being used across the organization over time.

It focuses on:

- Code suggestions
- Accepted suggestions
- Acceptance rates
- Lines of code accepted
- Developer engagement
- Adoption trends

---

## Key Performance Indicators

### Suggestions Count

The total number of code suggestions generated by GitHub Copilot.

### Acceptances Count

The total number of Copilot suggestions accepted by developers.

### Acceptance Rate

The percentage of suggestions accepted by developers.

$$
\text{Acceptance Rate} =
\frac{\text{Acceptances Count}}
{\text{Suggestions Count}}
\times 100
$$

A higher acceptance rate generally indicates that Copilot's suggestions are relevant and useful.

### Lines Suggested

The total number of lines of code suggested by Copilot.

### Lines Accepted

The total number of suggested lines retained by developers.

### Line Acceptance Rate

The percentage of suggested lines that developers accepted.

$$
\text{Line Acceptance Rate} =
\frac{\text{Lines Accepted}}
{\text{Lines Suggested}}
\times 100
$$

### Active Users — Completion

The number of reported users who engaged with Copilot code completion.
These measures are defined in [copilot_roi_powerbi_measures.dax](copilot_roi_powerbi_measures.dax#L1-L15).

> **Important:** This measure sums engagement across the available dimensions. When multiple dates, teams, languages, or editors are selected, the same developer may be represented more than once. It should not automatically be interpreted as a distinct organization-wide user count.

## Measures Used on This Page

### Suggestions Count

```dax
Suggestions Count =
SUM(FactCompletionByLanguageEditor[suggestions_count])
```

### Acceptances Count

```dax
Acceptances Count =
SUM(FactCompletionByLanguageEditor[acceptances_count])
```

### Acceptance Rate %

```dax
Acceptance Rate % =
DIVIDE(
	[Acceptances Count],
	[Suggestions Count],
	0
)
```

Format this measure as a **Percentage** in Power BI.

### Lines Suggested

```dax
Lines Suggested =
SUM(FactCompletionByLanguageEditor[lines_suggested])
```

### Lines Accepted

```dax
Lines Accepted =
SUM(FactCompletionByLanguageEditor[lines_accepted])
```

### Line Acceptance Rate %

```dax
Line Acceptance Rate % =
DIVIDE(
	[Lines Accepted],
	[Lines Suggested],
	0
)
```

Format this measure as a **Percentage** in Power BI.

### Active Users (Completion)

```dax
Active Users (Completion) =
SUM(FactCompletionByLanguageEditor[engaged_users])
```

### KPI Cards

Display the following measures as cards:

- Suggestions Count
- Acceptances Count
- Acceptance Rate
- Lines Accepted
- Line Acceptance Rate
- Active Users — Completion

### Adoption Trend Chart

Use a combined column and line chart:

- **X-axis:** Date
- **Column values:** Suggestions Count and Acceptances Count
- **Line value:** Acceptance Rate

This chart shows whether Copilot adoption and acceptance quality are improving over time.

Add slicers for:

- Date
- Team
- Programming language
- Editor

These filters allow users to investigate adoption across different parts of the organization.

## How to Interpret the Results

| Observation | Possible interpretation |
|---|---|
| Suggestions and acceptances are increasing | Copilot adoption is growing |
| Acceptance rate is high or improving | Suggestions are relevant and useful |
| Suggestions increase while acceptance rate decreases | Usage is growing, but suggestion quality or developer fit may require investigation |
| Active-user engagement is low | Adoption may be concentrated among a small group of developers |
| Line acceptance rate is high | Developers are retaining substantial portions of Copilot-generated code |
| Adoption differs significantly by team | Some teams may require additional training or enablement |
| Adoption differs by language or editor | Copilot may be more effective in particular development environments |

## Business Questions Answered

The Organization Adoption page helps answer:

1. Is GitHub Copilot usage increasing?
2. Are developers accepting Copilot suggestions?
3. Is the quality of suggestions improving?
4. Which teams have the highest or lowest adoption?
5. Which programming languages and editors show the strongest engagement?
6. Are developers retaining the generated lines of code?
7. Where could additional Copilot training or enablement be required?

---

## Summary

The Organization Adoption page combines **usage volume**, **acceptance quality**, and **developer engagement**. It provides an organization-level view of whether Copilot adoption is increasing and whether its suggestions are delivering useful development support.
